# 0008 — Langues du projet

Statut : Acceptée (2026-09-24)

## Décision
- **Anglais** : identifiants, commentaires et docstrings, noms de fichiers de code, messages de log techniques.
- **Français** : documentation (`docs/`), décisions, messages de commit, descriptions de PR, textes de l'interface, messages d'erreur montrés à l'utilisateur, prompts de génération (rédigés en français natif, jamais traduits).
- **Correspondance des termes** : `docs/produit/glossaire-domaine.md` fixe, pour chaque concept, le terme français et l'identifiant anglais. On n'invente pas de synonyme.
