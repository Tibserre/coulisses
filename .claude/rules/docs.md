# Documentation

- En français, phrases courtes, pas de remplissage. Une doc sert à décider ou à agir.
- La spec (`docs/produit/spec-v1.md`) décrit le **quoi** et le **pourquoi**. Le **comment** va dans un ADR.
- Un ADR accepté n'est pas réécrit : on le marque « Remplacé par 00XX » et on en écrit un nouveau. Tiens à jour l'index `docs/decisions/README.md`.
- Une question tranchée quitte `questions-ouvertes.md` et va dans la spec ou dans un ADR, dans le même commit.
- Ne suppose jamais le prénom ou les pronoms de l'utilisateur : écris « l'utilisateur ».
